# CampusConnect

CampusConnect is a responsive student service portal built for Lab 1 with mock data. Open `index.html` in a browser.

## Implemented interactions

- Theme switch
- Time-based greeting and live date/time
- Announcement search

## Future service mapping

| UI component | Future API |
| --- | --- |
| Attendance | `GET /attendance` |
| Courses | `GET /courses` |
| Announcements | `GET /announcements` |
| Fee payment | `POST /payment` |
